# **Image Classifier with Deep Learning**

The **Image Classifier** project is a deep learning-based application that classifies images into different categories using a pre-trained model. The model is trained on the **Oxford Flowers 102** dataset and utilizes **TensorFlow** and **Keras** for building and training the neural network. The application is designed to predict the class of input images, offering additional features like top-K predictions and category name mapping. The model uses **MobileNet** as the base model, fine-tuned for classifying flower species. It can predict multiple classes for each image, providing the top **K** predictions with probabilities, and the model is saved after training for future predictions. To run the project, clone the repository using `git clone https://github.com/your-username/image-classifier.git`, then train the model by running `python train_model.py`. After training, test the model by running `python predict.py --image_path path_to_your_image`, and for top-K predictions, use `python predict.py --image_path path_to_your_image --top_k 5`. If you want to map class numbers to human-readable category names, use `python predict.py --image_path path_to_your_image --category_names category_names.json`. The project uses **Python 3.x**, and you can install the required libraries by running `pip install tensorflow numpy matplotlib opencv-python`. The file structure includes `train_model.py` for training the model, `predict.py` for making predictions, `model.h5` for the saved trained model, and `category_names.json` for the class-to-name mapping.
